# Loading screen art

Full-size originals that Andrew owns (made in his licensed Canva account; the surf photo is AI-generated, then composed
there). These ship with the game: `tools/loadingArt.py` makes the sized copies the game loads (into `public/loading/`), so
only originals go here.

| File | What |
|---|---|
| `photo-wide.png` | the surf photo on its own: no emblem, as wide as Canva allows (3840 px or more) |
| `logo-emblem.svg` | the grasstree emblem alone, transparent background |
| `logo-wordmark.svg` | "Liquid Dreams" alone, transparent background |

`plants/`: plant photos Andrew took himself (his own, so they may ship). Plant photos from the web go in
`reference/dune/flora/` instead (git-ignored, never shipped), with a `sources.txt` listing where each came from.
