# Draco decoder

The three files here (`draco_decoder.js`, `draco_decoder.wasm`, `draco_wasm_wrapper.js`) are Google's Draco 3D mesh
decoder (https://github.com/google/draco), copied unchanged from three.js's `examples/jsm/libs/draco/`. three's
`DRACOLoader` uses them to decode `public/heath/heathKit.glb`.

They are third-party code under the Apache License, Version 2.0: see `LICENSE` beside them. They are not project-made,
unlike everything in `public/heath/`.
