# Reference sequences, set 2: ChatGPT prompts (2026-10-10)

One prompt per sequence. For each one: attach the start frame named in the heading (from `_start/`), paste the
prompt, and save the result as `reference/anim/<folder>/sheet.png`. If a sheet comes back wrong, the fixes that help
most are at the bottom.

**Camera rule (the important one):** the camera stays fixed for every frame. She turns and moves; the camera doesn't.
If the camera moves, I can only read the frames by eye. If it stays put, I can measure the joints exactly.

## If a sheet comes back wrong
- Camera moved or zoomed: "Redo it. The camera must be locked: identical position, height and zoom in all frames, like
  a tripod. Only the figure moves."
- She changes shape between frames: "Keep the mannequin's body proportions exactly the same in every frame."
- Too few or too many frames: "Exactly N frames, numbered."
- Water or waves crept in: "No water, no waves, plain light-grey background only."
- Separate images instead of a sheet are fine: name them 01.png, 02.png, ... in the sequence's folder.
